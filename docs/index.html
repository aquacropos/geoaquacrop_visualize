GeoAquaCrop Visualizer — Documentation

GeoAquaCrop Visualizer is an interactive web-based tool for exploring gridded AquaCrop simulations. Built with Python, Dash, and Plotly, it provides spatial and temporal exploration of simulation outputs and climate inputs across large multi-cell grids.

Note

The application is a Python package, geoaquacrop_plotting, split across 22 modules. Importing the package loads every dataset, pre-computes the aggregations, assembles app.layout, and registers every callback; Architecture explains that startup sequence and the strict one-way dependency order that makes it work.
