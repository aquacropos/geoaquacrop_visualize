Dash Callbacks

Callbacks are registered by importing the five callbacks_* modules, which geoaquacrop_plotting/__init__.py does after the layout exists — the callbacks reference component ids that must already be in the tree.

No callback reads another callback’s components. Every selection is written into a dash.dcc.Store, and the figure callbacks read from those stores: a single state bus that keeps the callback graph shallow and acyclic.

The state bus

Store id

Initial value

Holds

sel-tab

'output'

Which tab is active, 'output' or 'input'.

sel-crop

first crop

Selected '<crop> | <irrigation>' combination.

sel-season

first season

Selected harvest year, or 'all'.

sel-map-var

first map variable

Key into MAP_VARIABLES.

sel-daily-var

first daily variable

Key into DAILY_VARIABLES.

sel-clim-var

first climate variable

Key into CLIMATE_VARIABLES.

sel-agg

'mean'

Aggregation for multi-year views, 'mean' or 'sum'.

sel-out-cell

None

Cell id clicked on the output map.

sel-in-cell

None

Cell id clicked on the input map.

out-ts-clicks

{'count': 0, …}

Mean ± std window state on the output time series.

in-ts-clicks

{'count': 0, …}

Mean ± std window state on the input time series.

lasso-cells

[]

Cell ids from the most recent lasso or box selection.

sel-spam-var

''

Active SPAM physical-area variable, empty when none.

input-mode

'climate'

Whether the input map draws climate or SPAM.

Note

Several callbacks write the same figure property, so they declare allow_duplicate=True together with prevent_initial_call=True.

Callbacks for the sidebar controls: tab, crop, season, aggregation, and the map/daily/climate variable pickers.

Store the active tab index from tab button clicks.

geoaquacrop_plotting.callbacks_controls.toggle_tabs(sel_tab)[source]

Show or hide the output/input panels and their controls based on active tab.

geoaquacrop_plotting.callbacks_controls.set_crop(val)[source]

Store the selected crop and irrigation combination.

geoaquacrop_plotting.callbacks_controls.set_season(val)[source]

Store the selected season year or ‘all’.

geoaquacrop_plotting.callbacks_controls.set_agg(_)[source]

Store the selected aggregation function (‘mean’ or ‘sum’).

geoaquacrop_plotting.callbacks_controls.style_agg_btns(sel_agg)[source]

Update aggregation button styles to reflect the active selection.

geoaquacrop_plotting.callbacks_controls.toggle_agg_row(sel_season, sel_tab)[source]

Show the aggregation row only when ‘All years’ is selected on the output tab.

geoaquacrop_plotting.callbacks_controls.set_map_var(yield_v, water_v, wp_v)[source]

Merge map variable selections from three accordion dropdowns into one store.

Clears the other two dropdowns when one is selected so only one variable is active at a time.

geoaquacrop_plotting.callbacks_controls.set_daily_var(flux_v, soil_v, crop_v)[source]

Merge daily variable selections from three accordion dropdowns into one store.

Clears the other two dropdowns when one is selected.

geoaquacrop_plotting.callbacks_controls.set_clim_var(val)[source]

Store the selected climate variable and switch input mode to ‘climate’.

Selection

Callbacks for spatial and temporal selection: map cell clicks, lasso/box selection, the ribbon captions, and the time-series mean +/- std window.

geoaquacrop_plotting.callbacks_selection.set_out_cell(click_data)[source]

Extract and store the clicked cell ID from the output map click event.

geoaquacrop_plotting.callbacks_selection.set_in_cell(click_data)[source]

Extract and store the clicked cell ID from the input map click event.

geoaquacrop_plotting.callbacks_selection.handle_lasso(selected_data, whole_area)[source]

Process lasso or box selection events on the output map.

Extracts cell IDs from the invisible scatter layer’s text attribute. Clears the selection when ‘Whole area’ is checked in the export panel.

Parameters:

  • selected_data (dict or None) – Plotly selectedData event from the output map.

  • whole_area (list) – Export panel checklist value. Contains 'all' when whole area is selected.

Returns:

  • lasso_cells (list of int) – Selected cell IDs.

  • label (str) – Status label shown next to the export cells checklist.

geoaquacrop_plotting.callbacks_selection.update_ts_ribbon_text(cell_id, crop, season)[source]

Update the ribbon text above the output time series.

Shows cell ID, coordinates, crop type, and selected season when a cell is selected. Shows a prompt to select a cell otherwise.

geoaquacrop_plotting.callbacks_selection.update_input_ribbon_text(cell_id, clim_var, season)[source]

Update the ribbon text above the input time series.

Shows cell ID, coordinates, climate variable label, and selected season when a cell is selected.

geoaquacrop_plotting.callbacks_selection._handle_click(click_data, ts_clicks)[source]

Update the click state for the mean ± std window tool.

Implements a three-state cycle: first click sets the start date, second click sets the end date (auto-sorted so start < end), third click resets the state to allow a new selection.

Parameters:

  • click_data (dict or None) – Plotly clickData event from a time series graph.

  • ts_clicks (dict) – Current click state with keys count, start, end.

Returns:

dict – Updated click state dict.

geoaquacrop_plotting.callbacks_selection.handle_out_ts_click(click_data, ts_clicks)[source]

Handle click events on the output time series graph.

geoaquacrop_plotting.callbacks_selection.handle_in_ts_click(click_data, ts_clicks)[source]

Handle click events on the input climate time series graph.

geoaquacrop_plotting.callbacks_selection.reset_out_clicks(_, __, ___)[source]

Reset the output time series click state when cell, season, or variable changes.

geoaquacrop_plotting.callbacks_selection.reset_in_clicks(_, __, ___)[source]

Reset the input time series click state when cell, season, or variable changes.

Maps

Map-updating callbacks.

These patch only the z-values, hover text, and colour scale of the existing figures via dash.Patch, leaving the GeoJSON geometry in the browser – the single biggest reason interactions stay fast on large grids.

geoaquacrop_plotting.callbacks_maps.patch_output_map_data(sel_crop, sel_season, sel_map_var, sel_agg)[source]

Patch the output map’s data layer without re-sending the GeoJSON.

Uses dash.Patch to update only the choropleth z-values, locations, colorscale, colorbar title, and hover text. The GeoJSON geometry remains in the browser, making updates significantly faster than a full figure rebuild.

geoaquacrop_plotting.callbacks_maps.patch_output_map_highlights(sel_cell, lasso_cells)[source]

Patch the output map’s click and lasso highlight layers.

Updates trace indices 2 (clicked cell, blue) and 3 (lasso cells, orange) via dash.Patch without modifying the data or background layers.

geoaquacrop_plotting.callbacks_maps.update_cropcal_info(sel_crop, sel_tab)[source]

Update the crop calendar info text shown above the input map.

Displays planting date, season length, and approximate harvest date for the selected crop and irrigation type.

geoaquacrop_plotting.callbacks_maps.update_spam_buttons(sel_crop, spam_clicks, clim_val, current_spam_var)[source]

Rebuild the SPAM variable buttons for the selected crop.

Generates one button per matching SPAM variable. Sets input-mode to 'spam' when a SPAM button is clicked, or back to 'climate' when a climate variable button is clicked.

geoaquacrop_plotting.callbacks_maps.patch_input_map_data(sel_clim_var, sel_spam_var, input_mode, sel_season)[source]

Patch the input map’s data layer for both climate and SPAM modes.

In climate mode: updates z-values from the aggregated climate grid, with hover text using map_label and unit (e.g. mm/year). In SPAM mode: updates z-values from the SPAM physical area dataset, with hover text in hectares.

geoaquacrop_plotting.callbacks_maps.patch_input_map_highlight(sel_cell)[source]

Patch the input map’s click highlight layer (trace index 2).

Time series

Callbacks that rebuild the output and input time-series figures.

geoaquacrop_plotting.callbacks_timeseries.update_output_ts(cell_id, season_label, daily_var, ts_clicks)[source]

Rebuild the output time series figure and control its container visibility.

Derives the time period from season_label (‘all’ → full simulation, specific year → season only). Hides the container when no cell is selected.

geoaquacrop_plotting.callbacks_timeseries.update_input_ts(cell_id, clim_var, season_label, ts_clicks, sel_crop)[source]

Rebuild the input climate time series figure and control container visibility.

Passes sel_crop to build_input_ts so planting date lines use the currently selected crop’s calendar.

Export modal

Callbacks for the export modal: date dropdowns, variable merging, and the export run itself.

geoaquacrop_plotting.callbacks_export.toggle_date_dropdowns(whole_period)[source]

Disable all export date dropdowns when ‘Whole simulation’ is checked.

geoaquacrop_plotting.callbacks_export.merge_export_vars(flux, soil, crop)[source]

Merge variable selections from three export checklists into one store.

Parameters:

  • flux (list of str) – Selected water flux variable keys.

  • soil (list of str) – Selected soil water variable keys.

  • crop (list of str) – Selected crop growth variable keys.

Returns:

list of str – Combined list of all selected export variable keys.

geoaquacrop_plotting.callbacks_export.toggle_export_modal(open_n, close_n, is_open)[source]

Toggle the export modal open or closed based on button clicks.

geoaquacrop_plotting.callbacks_export.run_export(n_clicks, export_vars, whole_period, start_year, start_month, start_day, end_year, end_month, end_day, whole_area, lasso_cells, formats)[source]

Run the data export when the Export button is clicked.

Validates variable and format selections, resolves the date range and cell list, then calls export_data. Returns a status message shown next to the Export button.

Parameters:

  • n_clicks (int) – Number of times the Export button has been clicked.

  • export_vars (list of str) – Combined variable keys from all three export checklists.

  • whole_period (list) – Contains 'whole' if the whole simulation period is selected.

  • start_year (int) – Start date components from the dropdowns.

  • start_month (int) – Start date components from the dropdowns.

  • start_day (int) – Start date components from the dropdowns.

  • end_year (int) – End date components from the dropdowns.

  • end_month (int) – End date components from the dropdowns.

  • end_day (int) – End date components from the dropdowns.

  • whole_area (list) – Contains 'all' if the whole spatial area is selected.

  • lasso_cells (list of int) – Cell IDs from a lasso/box selection, used when whole_area is not set.

  • formats (list of str) – Selected export format codes from ['nc', 'tif', 'csv'].

Returns:

str – Status message displayed in the export panel.

geoaquacrop_plotting.callbacks_export.toggle_export_btn(sel_tab)[source]

Show the Export button only on the Simulation Outputs tab.

geoaquacrop_plotting.callbacks_export.constrain_end_date(sy, sm, sd, ey, em, ed)[source]

Constrain the export end date dropdowns so the end date cannot precede the start.

Filters year options to >= start year, month options to >= start month when in the same year, and day options to >= start day when in the same month and year. Also clamps the currently selected end values if they fall outside the new valid ranges.

Parameters:

  • sy (int) – Start year, month, day.

  • sm (int) – Start year, month, day.

  • sd (int) – Start year, month, day.

  • ey (int) – Currently selected end year, month, day.

  • em (int) – Currently selected end year, month, day.

  • ed (int) – Currently selected end year, month, day.

Returns:

tuple – Six values: updated options and values for the end year, month, and day dropdowns in order (year_opts, new_ey, month_opts, new_em, day_opts, new_ed).
