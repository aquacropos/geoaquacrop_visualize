Configuration and Helpers
=========================

The data-free layer: the settings module, the stateless helpers, the
read-only accessors over the loaded datasets, and the style factories.
``config``, ``utils``, and ``styles`` import nothing from the package that
touches a dataset, which is why the test suite can import all three for real
with no simulation data present.
