Figure Builders
===============

These functions construct complete Plotly figures. They are called once to
build the initial layout; afterwards the callbacks in ``callbacks_maps``
patch individual trace properties rather than calling them again. See
:doc:`../architecture` for the trace-order contract that makes those patches
safe.
