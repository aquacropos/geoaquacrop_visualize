geoaquacrop_plotting
--------------------

.. automodule:: geoaquacrop_plotting

Importing the package builds the entire application, and it re-exports the two
names a host needs:

.. list-table::
   :header-rows: 1
   :widths: 20 80

   * - Name
     - Meaning
   * - ``app``
     - The fully built :class:`dash.Dash` instance. ``app.server`` is its
       WSGI entry point.
   * - ``PORT``
     - The port from :data:`~geoaquacrop_plotting.config.PORT`, so a host can
       serve on the configured port without importing ``config``.

For convenience it also re-exports ``MAP_HEIGHT``, ``TS_HEIGHT``,
``CELL_RES``, ``EXPORT_DIR``, and the three variable catalogues from
:mod:`~geoaquacrop_plotting.config`.
