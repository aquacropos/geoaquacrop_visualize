GeoAquaCrop Visualizer — Documentation
=======================================

**GeoAquaCrop Visualizer** is an interactive web-based tool for exploring
gridded `AquaCrop <https://www.fao.org/aquacrop/en/>`_ simulations.
Built with Python, `Dash <https://dash.plotly.com>`_, and
`Plotly <https://plotly.com>`_, it provides spatial and temporal
exploration of simulation outputs and climate inputs across large
multi-cell grids.

Developed at the `GIST Lab <https://gistlab.science>`_, Aalto University,
Department of Built Environment, as part of the DIWA doctoral programme.
